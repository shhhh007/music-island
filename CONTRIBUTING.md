# Участие в проекте

Нашли ошибку? Откройте Issue: версия Windows, версия Music Island, плеер/браузер, шаги воспроизведения и ожидаемый результат. Скриншот поможет; удалите с него личные сведения.

Для изменений кода сначала прочитайте [инструкцию разработчика](docs/DEVELOPMENT.md). Делайте небольшие PR с описанием поведения до/после и выполненных проверок. Для изменений анимации приложите результаты интерактивного теста. Не включайте `settings.json`, журналы, реальные медиаданные и собранные бинарные файлы.
