# Разработка

## Сборка

Откройте Windows PowerShell в корне проекта:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\build.ps1
```

Используется встроенный компилятор .NET Framework и WinRT-метаданные Windows. Node.js, Python, NuGet и отдельный .NET SDK не нужны. Требуется Windows x64 с .NET Framework 4.8; сборка на Linux/macOS не поддерживается.

## Устройство приложения

| Файл | Назначение |
|---|---|
| `IslandView.cs` | WPF-отрисовка, анимация, управление и настройки |
| `Island.ps1` | Окно, трей и координация фоновых задач |
| `media-worker.ps1` | Медиасессии Windows и медиакоманды |
| `local-worker.ps1` | Опциональный сервер на localhost |
| `lyrics-worker.ps1` | Поиск синхронного текста в LRCLIB |
| `model-worker.ps1` | Подготовка данных вне UI-потока |
| `CoverBridge.cs` | Чтение обложек WinRT |
| `Launcher.cs` | Запуск приложения без консольного окна |
| `Installer.cs` | Установщик текущего пользователя |

Нативное окно имеет постоянную поверхность. При анимации меняется только отрисовка; окно не переносится и не растягивается на каждом кадре. Пружинка рассчитывается небольшими шагами. Медиапозиция привязана к метке времени источника, а не к частоте сообщений UI.

Макеты текста и замороженные рисунки глифов повторно используются при прокрутке, затухании и подсветке слов. Кэши ограничены 512 элементами; размер, насыщенность и DPI входят в ключ. Прозрачность применяется отдельно от текста. Фоновая модель собирается только при смене снимка источника, а одинаковый JSON не разбирается повторно. Скрытое окно не рисует кадры; при показе его отсчёт времени кадра сбрасывается. Частота видимых анимаций и тайминги текста не ограничиваются этими оптимизациями.

## Проверка

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\test.ps1
```

Тест интерфейса работает около 18 секунд, пропускает клики и отправляет команды тестовому обработчику, не настоящему плееру. Проверяются анимация, геометрия, прогресс, кнопки, громкость, перемотка, длинные и короткие строки, часы и горячая клавиша. Нужен интерактивный рабочий стол Windows.

Интеграция с реальным плеером:

```powershell
powershell -NoProfile -STA -ExecutionPolicy Bypass -File .\Island.ps1 -SelfTest
```

Результаты проверок и изображения не включаются в Git: они могут содержать реальные медиаданные.

## Релиз

Обновите `VERSION`, затем:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\package.ps1
```

В `dist` появятся Setup EXE, portable ZIP и SHA-256. В пакет входят только явно перечисленные файлы. Личные настройки, журналы и утилиты публикации исключены. Скрипт проверяет содержимое пакета; интерактивные проверки выполняются локально. Пример необязательной автоматизации GitHub Actions находится в `docs/automation-example.yml`: для включения переместите его в `.github/workflows/build.yml` через авторизованный интерфейс GitHub.

## Совместимый локальный сервер

Опциональные GET-маршруты: `/state`, `/tick`, `/art`, `/config?bands=5&music_only=1&equalizer=1`, `/control?action=volume&value=0.5`. Сам сервер не поставляется. Без него работают медиасессии Windows, цвет из обложки и поиск текста в LRCLIB; частотный эквалайзер, громкость приложения и серверные тайминги слов недоступны.
