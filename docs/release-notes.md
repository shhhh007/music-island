## Следующий выпуск — ещё не опубликован

- Исправлено чтение UTF-8, включая кириллицу и emoji, в ответах сервиса текста и локального сервера.
- Поиск учитывает служебные пометки в названиях и формат «исполнитель — трек». Проверяются название, исполнитель и длительность; чужая версия, пустой или инструментальный результат не подставляются.
- После смены песни устаревший поиск прекращается. Временные сетевые ошибки допускают повтор, а отсутствие синхронного текста не заменяется выдуманными строками.
- Сохранены оптимизации отрисовки текста и подготовки данных.
- Добавлена сборка с проверкой доверенной подписи всех исполняемых компонентов и установщика. Подписанный пакет и запуск на Windows с активной защитой пока требуют сертификата издателя и отдельной проверки.

Исправления находятся в `main`. Скачиваемый установщик 1.0.0 остаётся прежним. [Подпись и статус выпуска](SIGNING.md).

## Music Island 1.0.0

Первый публичный выпуск музыкального острова для Windows.

### Скачать

- **Music-Island-1.0.0-Setup.exe** — установка для текущего пользователя, ярлыки и удаление через меню «Пуск».
- **Music-Island-1.0.0-portable.zip** — переносимая версия; извлеките все файлы и запустите Music Island.exe.
- **SHA256SUMS.txt** — контрольные суммы.

### Что внутри

Обложка и медиакоманды Windows, пружинное раскрытие, цвет из обложки, синхронный текст из LRCLIB, настройки, трей и Ctrl+Alt+I. Исправлены дёрганье окна, откаты прогресса и завершение приложения при скрытии.

Windows 10 1809+ / Windows 11 x64, .NET Framework 4.8. Для игр — оконный режим без рамок. Эквалайзер по частотам, громкость приложения и серверные тайминги слов требуют опционального сервера на localhost, который не входит в пакет. Установщик пока не подписан сертификатом издателя.
