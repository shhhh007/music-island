# Текст песни в Music Island

Нажми правой кнопкой на значок Music Island возле часов → **Источники текста / свой .lrc**.

**LRCLIB** работает автоматически, без регистрации. Проверяются название, исполнитель и длительность записи.

**Musixmatch** используется, если LRCLIB не нашёл синхронный текст. Получи свой API-ключ на https://developer.musixmatch.com и убедись, что тариф разрешает `matcher.track.get` и `track.subtitle.get`. Вставь ключ в окно источников и сохрани. Доступ и полнота каталога зависят от провайдера. Ключ хранится локально с шифрованием Windows для текущей учётной записи. Чтобы удалить ключ, сохрани пустое поле.

**Свой текст:** включи песню, нажми «Выбрать .lrc для текущей песни» и выбери файл UTF-8 с таймингами:

```text
[00:12.30]Первая строка
[00:17.80]Следующая строка
```

Он имеет приоритет и привязывается к записи и её длительности. Тайминги должны соответствовать проигрываемой версии. «Убрать свой текст» возвращает автопоиск и сохраняет прежний файл с суффиксом `.removed`.

Данные находятся в `%LOCALAPPDATA%\MusicIsland\Lyrics`. Не публикуй эту папку. Ни один источник не гарантирует текст каждой песни, особенно ремиксов и редких загрузок SoundCloud. Приложение не генерирует отсутствующий текст и не выдаёт текст без таймингов за синхронный.
